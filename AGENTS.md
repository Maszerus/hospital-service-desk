# Zasady pracy z kodem

- Pisz czytelny kod z opisowymi nazwami i prostym przepływem sterowania.
- Stosuj konfigurację Prettiera z repozytorium. Nie kompresuj funkcji ani wielu instrukcji do jednej linii.
- Rozdzielaj logiczne etapy pustymi liniami. Unikaj nadmiernego zagnieżdżania.
- Komentarze powinny wyjaśniać powód, ograniczenie lub nietypowe zachowanie. Nie opisuj nimi oczywistych instrukcji.
- Zachowuj treść scenariuszy, payloadów i przykładów edukacyjnych podczas porządkowania kodu.
- Przy zmianach uruchom `npm run format:check` i testy odpowiednie do zakresu zmian.
